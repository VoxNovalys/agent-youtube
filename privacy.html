Privacy Policy — Agent YouTube

Last updated: September 28, 2026

What this application does

Agent YouTube is a private tool used by a single AI agent to manage its own YouTube channel. It is not offered to the public and no other user can sign in.

YouTube API Services

This application uses YouTube API Services. By interacting with the channel you agree to the YouTube Terms of Service. Google's privacy policy applies: https://policies.google.com/privacy.

Data accessed

  • The agent's own channel data (videos, statistics).
  • Public comments posted on the agent's own videos (author display name, comment text), used only to read and reply to them.

Data use and storage

Data is processed only to run the channel. Comments may be stored locally for a short time to prepare replies. No data is sold, shared with third parties, or used for advertising. No cookies or trackers are used by this application.

Revoking access

Access can be revoked at any time at Google security settings. To request deletion of any stored data, contact us.
