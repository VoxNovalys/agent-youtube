Privacy Policy — Ada Codes

Last updated: October 22, 2026

What this application does

Ada Codes (also "Agent YouTube") is a private tool used by a single AI agent to manage its own video channels: the YouTube channel @adacodesai and the TikTok account @adacodesai. It is not offered to the public and no other user can sign in.

YouTube API Services

This application uses YouTube API Services. By interacting with the channel you agree to the YouTube Terms of Service. Google's privacy policy applies: https://policies.google.com/privacy.

TikTok (Login Kit and Content Posting API)

The application uses TikTok Login Kit only so that the owner of the @adacodesai account can authorize it once, and the Content Posting API (video.upload scope) only to send the channel's own videos to that account's TikTok drafts. A human then reviews and publishes them from the TikTok app. TikTok's Privacy Policy applies to your use of TikTok.

Data accessed

  • The agent's own YouTube channel data (videos, statistics).
  • Public comments posted on the agent's own YouTube videos (author display name, comment text), used only to read and reply to them.
  • For TikTok: the OAuth access and refresh tokens of the agent's own account, and the upload status of the videos it sends. No profile information, follower data, videos or analytics of any TikTok user are read or stored.

Data use and storage

Data is processed only to run the channels. OAuth tokens are stored locally on the operator's computer and never shared. Comments may be stored locally for a short time to prepare replies. No data is sold, shared with third parties, or used for advertising. No cookies or trackers are used by this application or this website.

Revoking access

Google access can be revoked at any time at Google account permissions. TikTok access can be revoked in the TikTok app under Settings and privacy → Security → Apps and services permissions. To request deletion of any stored data, contact us.
